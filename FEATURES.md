# PrismLink – feature ideas to make it better

**Shipped:** email/password auth, link CRUD, drag-and-drop reorder, show/hide toggle, 8 gradient themes, button styles/shapes, live phone preview, views/clicks analytics, QR code, username change, mobile app-style UI.

**Next up (high impact)**
1. Social icon row under the bio (Instagram, X, YouTube…) separate from link buttons
2. Image upload for avatar + custom background image/colour picker (Firebase Storage)
3. Link thumbnails / icons picker and emoji support
4. Scheduled links (show between dates) and "expires" timers
5. Link groups / collapsible sections and headers/dividers
6. Time-series analytics (daily chart), referrers, device and country breakdown
7. Embeds: YouTube, Spotify, SoundCloud players inline
8. Custom domains and short links (prismlink.app/you → your.domain)
9. Email/newsletter capture block and contact form
10. Link "spotlight" animations (pulse, shake) and featured/large cards
11. Sensitive-content gate and password-protected links
12. Dark/light dashboard toggle and PWA install (installable app)
13. SEO + Open Graph preview cards per profile, verified badge
14. Google/Apple/GitHub sign-in alongside email, plus email verification
15. Team/multi-page accounts, A/B tests, UTM builder, bulk import
16. Server-side click dedupe & bot filtering (Cloud Functions)
